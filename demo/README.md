# 示範會議

`2026-01-15_產品週會-示範/` 是一場已經轉好的示範會議，全新安裝第一次啟動校對工具時會自動複製到 `meetings/`，打開就有一場可以試；不想要的話把 `meetings/` 裡那個資料夾刪掉就好，不會再跑回來。

**這場會議是語音合成的，不是真人錄音；對話內容、公司與人名都是虛構的。**

## 怎麼做出來的

| 檔案 | 來源 |
|---|---|
| `劇本.txt` | 手寫的虛構對話（兩位講者，1 分 21 秒） |
| `source.m4a` | `python utils/make_demo_audio.py` 把劇本用 Google Gemini 的語音合成模型（`gemini-3.8-flash-tts`，聲音 Leda 與 Charon，語言 cmn-TW）唸出來 |
| `glossary.txt` | 這場會議的詞彙表（手寫） |
| `audio/`、`transcripts/`、`project.json` | `python pipeline/run.py` 的產出：Gemini 轉錄加 whisper 對照，沒有手動修改逐字稿 |
| `meeting.json` | `run.py` 產生，標題改成「產品週會（示範）」 |
| `project.json` 裡的講者名稱 | 手動填入（Amy、王小明） |
| `notes.json`、`notes.md` | `python pipeline/notes.py`（一般會議範本）整理的會議紀錄 |

處理時沒有使用任何全域詞彙表或聲紋資料，所以結果只取決於這個資料夾裡的東西。

## 可以拿來試什麼

- 點一行聽那一句、改字、接受；切換「顯示 whisper」看第二個引擎的對照。
- 「AI 工具」分頁的「清語助詞」：逐字稿裡留著「呃」「那個」「就是」這些口語。
- 「會議紀錄」分頁：每一條都附時間點，點了會跳到那一行播放；最下面有 4 題「待確認」可以作答後重新整理。
- 語音合成的聲音很清楚，所以這場沒有可疑行，也沒有錯字建議；真實的會議錄音通常會有。
- 想確認安裝好的轉錄流程：把 `source.m4a` 與 `glossary.txt` 複製到 `meetings/` 底下新的資料夾，再按「開始轉錄」。
